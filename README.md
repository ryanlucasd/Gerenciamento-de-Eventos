# Sistema de Gerenciamento de Eventos

## 1. Descrição do Projeto

Este projeto consiste no desenvolvimento de um sistema orientado a objetos
para gerenciamento de eventos.

O sistema permite cadastrar e organizar informações relacionadas a eventos,
participantes e palestrantes.

## 2. Objetivo

O objetivo do projeto é aplicar os principais conceitos de Programação
Orientada a Objetos utilizando a linguagem Java.

## 3. Tecnologias Utilizadas

- Java
- IntelliJ IDEA
- Git
- GitHub

## 4. Estrutura do Sistema

O sistema é composto por diferentes classes que representam os elementos
envolvidos no gerenciamento de eventos.

Entre elas estão:

- Evento
- Participante
- Palestrante

Cada classe possui seus próprios atributos e métodos, seguindo os princípios
da Programação Orientada a Objetos.

## 5. Conceitos de POO Utilizados

Durante o desenvolvimento foram utilizados conceitos como:

- Classes e objetos
- Atributos
- Métodos
- Encapsulamento
- Construtores
- Getters e Setters
- Relacionamento entre classes

## 6. Como Executar

1. Baixe ou clone o repositório.
2. Abra o projeto no IntelliJ IDEA.
3. Configure o JDK do projeto.
4. Localize a classe principal.
5. Execute o programa.
